# Project Desk Local V2.3

这是 Project Desk 的本地单机 Python 桌面版，适合公司电脑离线使用或后续打包成 Windows exe。

本目录是 Project Desk 桌面版的维护入口；独立的 `project-manage-desktop` 仓库已合并回主仓并归档。

## V2.3 更新重点

- **侧边栏入口主页面化**：任务计划、总览、临时任务、项目档案、任务表格、日报记录、风险看板、数据中心都在主区域切换，不再打开大视图弹窗。
- **数据安全增强**：损坏的 `workspace.json` 会先保留副本，并自动尝试最近可用备份；无可用备份时新建示例工作区。
- **备份策略优化**：无真实数据变化时不写文件、不生成备份；备份文件名精确到毫秒，并自动保留最近 50 份。
- **合并导入更安全**：合并导入会重新生成项目、任务、日报、档案、临时任务 ID，并重映射父任务、日报、档案和临时任务关联。
- **日报与进度修复**：重复日报新增时提示编辑已有日报或取消；编辑任务不改进度时不再自动新增历史进度记录。
- **表单体验修复**：项目 Deadline、任务实际完成日改为日期控件；新任务默认风险为 M；延期日报未填原因时在弹窗内拦截，不丢失内容。
- **导出与系统行为**：导出默认文件名过滤 Windows 非法字符；超长 Excel 甘特导出前提示并写入截断说明；Windows 下增加单实例保护。
- **数据版本标记更新**：保存的 workspace 版本标记改为 `ProjectDeskLocal-V2.3-StabilityPages`。

## V2.2 更新重点

- **总览改为主页面**：左侧“总览”不再弹出大窗口，而是在主区域展示全部项目看板；双击项目或点击“进入任务计划”即可切回对应项目。
- **默认入口更清晰**：启动后左侧默认高亮“任务计划”，避免“总览”高亮但主区域显示单项目计划的认知冲突。
- **任务计划交互提示增强**：任务计划副标题改为明确说明“点击左侧任务字段查看详情；点击右侧日期查看当日日报”，鼠标悬停任务行会显示手型指针。
- **任务/日报/档案弹窗中文化**：任务状态改为中文显示，确认/取消按钮中文化；任务开始日期、日报日期、档案日期、临时任务日期改为日期选择控件。
- **归档路径输入更顺手**：任务详情和档案弹窗的归档路径输入框加宽，文件和目录选择拆成两个按钮，长路径更容易核对。
- **项目档案空状态优化**：无档案时显示引导文案；未选中档案时自动禁用“编辑档案 / 删除档案 / 打开路径”，避免误点后弹提示。
- **临时任务操作优化**：无临时任务时显示引导；未选中记录时禁用相关操作；“归档到当前项目”改名为“手动归档到项目”，与实际支持选择目标项目/关联任务保持一致。
- **数据版本标记更新**：保存的 workspace 版本标记改为 `ProjectDeskLocal-V2.2-UXPolish`。

## V2.1 更新重点

- **项目档案与任务联动**：在“新增/编辑任务”窗口里可以直接选择归档文件或目录路径，保存任务后会自动在当前项目档案中生成/更新对应档案记录。
- **项目档案按项目展示**：左侧“项目档案”现在展示全部项目档案，表格第一列显示项目名，并支持按项目、类型、状态、关键词筛选。
- **任务计划视图扩大**：压缩了项目状态、Deadline、摘要信息区域高度，主界面的任务计划视图占比更大，可显示更多任务行。
- **底部上下文改为选项卡**：底部不再同时铺开“日报”和“任务详情”。点击任务计划左侧任务字段时切到“任务详情”；点击右侧甘特日期时切到“选中日期日报”。
- **总览独立成全部项目看板**：左侧“总览”会打开全部项目总览，集中查看每个项目的 deadline、计划/实际进度、任务完成情况、逾期数和档案数。
- **临时任务支持手动归档到指定项目/任务**：临时任务收集箱中“归档到项目”会弹出目标项目与关联任务下拉框，可手动选择归档层级。

## 运行

在 PyCharm 中打开仓库后，选择 `local_desktop/main.py` 运行。首次运行前安装依赖：

```powershell
cd local_desktop
python -m pip install -r requirements.txt
python main.py
```

Windows 用户也可以直接运行 `run_app.bat`，脚本会先检查必要依赖再启动桌面版。

默认数据位置：

```text
%APPDATA%/ProjectDeskLocal/workspace.json
```

保存发生真实数据变化时，会在：

```text
%APPDATA%/ProjectDeskLocal/backups/
```

生成一份备份，并自动保留最近 50 份。

## 当前功能

- 本地单机运行，不需要登录。
- 多项目管理、任务计划、日报记录、风险看板、数据导出。
- 一体化任务计划视图：左侧冻结任务字段，右侧横向甘特时间轴。
- 项目档案：实验数据、会议纪要、汇报PPT、图片截图、交付版本等统一归档。
- 临时任务收集箱：先记录临时事项，再建议/手动转任务、归档或新增项目。
- 导入网页版 JSON，兼容 workspace、legacy payload、旧 localStorage 结构。
- 导出完整 JSON、当前项目 CSV、项目 Excel。

## 打包 exe

```powershell
cd local_desktop
.\build_exe.bat
```

输出：

```text
local_desktop/dist/ProjectDeskLocal/ProjectDeskLocal.exe
```

## 与网页版差异

- 本地版不连接 Supabase，不支持云同步和公开分享链接。
- 本地版更偏“个人/部门离线工作台”，用于任务推进、数据归档和结论追溯。
