# Project Desk Local

这是 Project Desk 的本地单机 Python 桌面版。它不需要登录、不连接 Supabase，数据保存在本机 JSON 文件中，适合公司电脑离线使用或后续打包成 Windows exe。

## 本次 UI 重构说明

这一版按新的商用项目管理工具 Demo 进行了界面重构：

- 新增左侧导航栏，整体更接近商用 PM 工具布局。
- 顶部保留项目标题、项目摘要、项目选择器和核心操作。
- 指标区展示项目状态、Deadline、实际进度、计划进度、逾期任务。
- 任务台账与甘特图合并为「任务计划视图」：左侧冻结任务字段，右侧横向甘特时间轴。
- 下方「选中日期日报」会跟随甘特图点击日期切换。
- 右下角新增「任务详情」，点击任务后展示负责人、风险、状态、进度和备注。
- 「今日关注」由规则自动生成，例如逾期任务、进度落后、今日日报缺失、高风险任务。

## 运行

在 PyCharm 中打开仓库后，选择 `local_desktop/main.py` 运行。首次运行前安装依赖：

```powershell
cd local_desktop
python -m pip install -r requirements.txt
python main.py
```

默认数据位置：

```text
%APPDATA%/ProjectDeskLocal/workspace.json
```

每次保存会在：

```text
%APPDATA%/ProjectDeskLocal/backups/
```

生成一份备份。

## 当前功能

- 本地单机运行，不需要登录。
- 支持项目新增、设置、删除。
- 支持任务新增、编辑、删除；删除任务会同步删除子任务和相关日报。
- 支持日报新增、编辑、删除；日报保存会同步回写任务进度，延期日报必须填写原因。
- 支持一体化任务计划视图：冻结任务列、横向甘特图、今日线、选中日期线、任务条、计划/实际进度、周末背景、逾期/高风险标识。
- 支持点击甘特图日期切换下方日报记录。
- 支持点击/双击甘特图任务选择与编辑任务。
- 支持导入网页版 JSON。
- 支持导出完整 JSON 备份。
- 支持导出任务 CSV，Excel 可打开，UTF-8 BOM。
- 支持导出 `.xlsx` 项目管理表。
- “打开数据目录”可直接打开本地数据文件夹。

## 打包 exe

```powershell
cd local_desktop
.\build_exe.bat
```

输出：

```text
local_desktop/dist/ProjectDeskLocal/ProjectDeskLocal.exe
```

## 与网页版差异

- 本地版不支持 Supabase 云同步、公开分享链接、小程序端能力。
- 本地版更适合公司内网或单机离线场景。
- 任务表格内联编辑仍未实现，当前通过弹窗编辑。

## 本次 UI 修复说明

- 任务计划视图的表头已改为冻结绘制：上下滚动时，风险、任务名称、负责人、状态、实际进度和日期刻度不会再被任务行覆盖。
- 甘特图不再绘制“今日”文字标签，改为红色竖线和小三角标记，避免和日期重叠。
- 左侧导航栏已改为可点击功能按钮：总览/任务计划回到主视图，任务表格、日报记录、风险看板、数据中心会打开对应功能视图。
- 左下角项目健康度会随逾期任务和进度落后任务自动更新。
