# Project_Manage_LocalV3.5

## V3.5 更新重点

- **日报默认关联当前任务**：从每日任务总览或甘特图选中任务后写日报，弹窗默认选中该任务。
- **日报自动带出负责人**：新增日报时自动使用任务台账中的负责人，减少重复输入。
- **任务详情布局修复**：底部任务详情区域提高可用高度，标题、元信息、进度和备注不再互相挤压。
- **数据版本标记更新**：保存的 workspace 版本标记改为 `Project_Manage_LocalV3.5`。

## V3.4 更新重点

- **统一现代弹窗**：新增/编辑项目、任务、日报、档案和待归档任务弹窗改为统一白色卡片布局。
- **统一消息提示**：常用信息、警告、确认删除、导入方式选择改为项目内统一样式。
- **程序图标**：新增深蓝项目罗盘图标，并用于窗口、任务栏、exe 和 Setup 安装快捷方式。
- **数据版本标记更新**：保存的 workspace 版本标记改为 `Project_Manage_LocalV3.4`。

## V3.3 更新重点

- **任务计划布局修复**：任务字段区与甘特图区分区绘制并强制裁剪，任务条不会再画进左侧任务信息区。
- **支持拖拽分栏**：甘特图左侧任务字段与右侧时间轴之间增加可拖拽分隔线，窗口变化时保留最小时间轴宽度。
- **已完成项自动后置**：Closed 任务默认排在未完成任务后面；已完成项目默认排在项目选择和看板列表末尾。
- **数据版本标记更新**：保存的 workspace 版本标记改为 `Project_Manage_LocalV3.3`。

## V3.2 更新重点

- **待归档任务目标项目明确化**：手动转任务前需要先选择目标项目，按钮会显示“转为某项目任务”，避免“当前项目”含义不清。
- **任务表格升级为任务台账**：默认跨项目查看全部任务，增加项目、状态、风险和关键词筛选。
- **日报记录升级为全项目流水**：默认显示全部项目日报，可按项目、结果和关键词筛选；编辑/删除时自动定位到日报所属项目。
- **数据版本标记更新**：保存的 workspace 版本标记改为 `Project_Manage_LocalV3.2`。

## V3 更新重点

- 每日任务总览的日期选择改为点击弹出日历。
- 保留 V2.4.1 后续修复：日期范围包含任务开始日、删除日报后重算任务状态、JSON 导入工期容错。
- 为兼容旧数据，本地数据目录仍沿用 `%APPDATA%/ProjectDeskLocal/workspace.json`。

这是 Project Desk 的本地单机 Python 桌面版，适合公司电脑离线使用或后续打包成 Windows exe。

## V2.4.1 修复重点

- **每日任务总览日期修复**：总览日期输入现在支持 `YYYY-MM-DD`、`2026-6-2`、`6.2`、`6/2`、`0602` 等写法，并会自动归一化为 `YYYY-MM-DD`。
- **跨项目任务判定增强**：任务起始日期/日报日期即使存在非补零格式，也会尽量归一化后参与“日期范围覆盖当天 / 今日截止 / 已逾期 / 已有日报”的判断。
- **兼容旧数据**：导入旧版完整 JSON 时会自动归一化常见日期格式，避免已录入项目和任务丢失。

## V2.4 更新重点

- **总览改为每日任务总览**：跨项目查看选中日期需要处理的任务，不再只按当前项目查看。
- **今日任务判定规则**：任务日期范围覆盖当天、今日截止、已逾期未关闭，或当天已有日报记录，都会进入每日任务总览。
- **跨项目快捷操作**：每日任务总览中可双击进入对应项目，也可以一键写日报或编辑任务。
- **项目看板独立保留**：原“全部项目总览”改为左侧“项目看板”，用于集中查看所有项目的 deadline、进度、任务数、逾期数和档案数。
- **临时任务改名为待归档任务**：左侧导航和页面文案统一改为“待归档任务/待归档任务收集箱”，更贴合先收集、再归档、再转任务/建项目的工作流。
- **兼容旧数据**：继续兼容 V2.1/V2.2/V2.3 导出的完整 JSON；旧字段 `inboxTasks` 和旧状态“待处理/已转任务/已归档/已建项目”仍可导入。
- **数据版本标记更新**：保存的 workspace 版本标记改为 `Project_Manage_LocalV3.1`。

## V2.1 基线功能

- 项目档案与任务联动：在“新增/编辑任务”窗口里可以直接选择归档文件或目录路径，保存任务后会自动在当前项目档案中生成/更新对应档案记录。
- 项目档案按项目展示：左侧“项目档案”展示全部项目档案，表格第一列显示项目名，并支持按项目、类型、状态、关键词筛选。
- 任务计划视图：左侧冻结任务字段，右侧横向甘特时间轴。
- 底部上下文选项卡：点击任务计划左侧任务字段时切到“任务详情”；点击右侧甘特日期时切到“选中日期日报”。
- 待归档任务收集箱：先记录临时事项，再建议/手动转任务、归档或新建项目。

## 运行

在 PyCharm 中打开仓库后，选择 `local_desktop/main.py` 运行。首次运行前安装依赖：

```powershell
cd local_desktop
python -m pip install -r requirements.txt
python main.py
```

默认数据位置：

```text
%APPDATA%/ProjectDeskLocal/workspace.json
```

## 导入你已导出的完整 JSON

打开程序后进入：

```text
顶部“数据”菜单 → 导入 JSON
```

建议先选择“合并到当前数据”或确认备份后再选择“覆盖当前全部本地数据”。本版本兼容之前已经导出的完整版 JSON，不需要重新手工录入项目。

## 打包 exe

```powershell
cd local_desktop
.\build_exe.bat
```

输出：

```text
local_desktop/dist/Project_Manage_LocalV3.5/Project_Manage_LocalV3.5.exe
```

## 生成 Setup 安装程序

```powershell
cd local_desktop
.\build_setup.ps1
```

输出：

```text
local_desktop/dist/Project_Manage_LocalV3.5_Setup.exe
```

安装程序会把主程序安装到：

```text
%LOCALAPPDATA%/Programs/Project_Manage_LocalV3.5
```

## 与网页版差异

- 本地版不连接 Supabase，不支持云同步和公开分享链接。
- 本地版更偏“个人/部门离线工作台”，用于任务推进、数据归档和结论追溯。
